# TnSeq_Pseudomonas_Genotype
 Repository for comparisons of Tnseq results across two Pseudomonas strains and two plants genotypes.

The script relates to TnSeq trials done in Utah with p25.c2 and DC3000.

1. Script for compiling the data from the different tnseq trials:
   ~/Documents/GitHub/TnSeq_Pseudomonas_Genotype/scripts/fitness_exp/compile_all_tnseq_trials_2025_amended_924_2025.R
   
2. Script for running limma voom on the compiled counts table:
   ~/Documents/GitHub/TnSeq_Pseudomonas_Genotype/scripts/fitness_exp/limmaVoom_full_table_2025.R

3. Script for relating fitness measurements to population genetic metrics:
   ~/Documents/GitHub/TnSeq_Pseudomonas_Genotype/scripts/fitness_exp/fitness_popgen_random_forest_combined_2025.R
   
4. Script for gene ontology comparisons:
   ~/Documents/GitHub/TnSeq_Pseudomonas_Genotype/scripts/fitness_exp/gene_ontology_contrasts_2025.R
